What is a SymphonyCSV file? It's a simple, readable way to describe what an instrument should play: notes, timing, and performance details in a CSV file. Studio reads the instructions and plays the music. The CSV is where you write or edit the composition; Studio is where you audition and mix it.
Choosing an instrument sound

What's a SoundFont? And how is it different from a VST?

You might know the sound of a piano, a guitar, or a drum kit without knowing how a computer makes it. SoundFonts are one way to give your musical notes a voice.

The sounds · .sf2 file

SoundFont

A SoundFont is a library of instrument sounds. It usually contains recorded samples, plus settings that tell a compatible player which sound to use when you play a note.

In SymphonyCSV Studio: Choose a SoundFont for your musical track. Studio's built-in playback engine uses it to turn your notes into sound. You don't need a DAW or VST plug-in.

For example: choose an upright-piano SoundFont to hear your pitched part as a piano.

The software · instrument or effect plug-in

VST

VST stands for Virtual Studio Technology. A VST is a type of plug-in used in compatible music software, often a DAW. A VST instrument produces sound; a VST effect processes sound, such as adding reverb or delay.

In a DAW like REAPER: Add a VST instrument to a track, choose its sound, and let it play your MIDI notes. Some VST instruments can load SoundFonts, but a SoundFont is not itself a VST plug-in.

What happens when you take your demo into a DAW?

Suppose you compose a piano part in Studio and audition it with an upright-piano SoundFont. If you export MIDI and open it in REAPER or another DAW, your notes and timing can travel with you—but that SoundFont sound does not automatically become the DAW's instrument. Choose a VST instrument, or load the SoundFont in a compatible sampler, to hear the MIDI there.

If you export WAV or MP3 instead, you're exporting recorded audio of the sound Studio rendered, including the instrument and mix settings used for that export.

How we measure usage

A few counts, never your music.

We use privacy-conscious aggregate measurements to learn whether SymphonyCSV Studio is helping musicians. This is not an account system and does not track your individual songs.

What may be counted?

Website visits: when enabled, Cloudflare Web Analytics measures page visits and performance in aggregate. Studio ready: a count when the core Studio interface initializes. Project export: one count when a logical Project ZIP export is initiated, including paired Music + Audio ZIP downloads.

Our custom Studio events contain only the event name and version. The custom event service stores daily totals, not IP addresses or browser identifiers. Cloudflare still receives ordinary network connection information while processing requests. We do not send CSV rows, composition titles, MIDI, SoundFonts, WAV recordings, Project ZIP contents or other music data to analytics.

Counts are approximate: blocked requests, repeated loads, offline use or automated traffic can affect them. A page visit does not prove someone composed music, and an export count does not prove a file was retained. Our custom event reporter respects browsers that signal Global Privacy Control or Do Not Track.

Don't lose your song

Keep a copy you control.

Save a Project ZIP

Download a portable Music Project ZIP when you want a durable copy of the composition and settings. If your song uses separately imported WAV recordings, keep their companion Audio ZIP with the music project.

This is the safest way to keep a copy outside your browser.

Save to Browser

Use More → Save to Browser for a convenient local session snapshot. Recover Session restores it in the same browser profile; Clear Saved Session removes that saved copy.

Browser data can be cleared, so it shouldn't be your only backup.

Helpful answers

A few things worth knowing.

  • Do I need an AI assistant?

    No. You can write and edit SymphonyCSV files yourself. AI help is optional.

  • Can AI help me compose?

    Yes. Give it the official CSV specification and a blank template, ask it to write a part in that exact format, then import the result into Studio to check it.

  • Does Studio have a graphical note editor?

    Studio's composition workflow is CSV-first. You author or import the musical data, and Studio handles validation, playback, mixing and export.

  • What if my CSV won't import?

    Check that you chose the correct track type, kept the exact column names, and supplied the required musical data. Studio's validation feedback can help identify the problem.

  • How do I choose an instrument sound?

    Studio plays musical tracks using SoundFonts. See SoundFonts and VSTs explained to learn how they work and what happens when you export MIDI to a DAW.

  • Where can I find every CSV field?

    Open the CSV format reference for detailed column-by-column descriptions and examples, including guidance for AI assistants.
