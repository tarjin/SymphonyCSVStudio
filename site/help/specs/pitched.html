Importing MIDI panning

When converting a MIDI file to Piano Roll Tracks 1–2, Studio captures the active channel CC10 pan at each note or hit onset and writes a whole-number Pan_Position from −100 (left) to +100 (right). MIDI CC10 64 maps to explicit centre (0). When no pan controller was provided, the cell stays blank, retaining the SoundFont's native placement. MIDI CC121 resets pan to centre. Changes during sustained notes cannot be reproduced as a continuous sweep.

Read the full MIDI pan import explanation for multi-track ordering, controller limitations and conversion behaviour.

Expressive note performance in MIDI

Each Pitched CSV note carries its own velocity (MIDI attack strength, 1–127), note timing and duration. The optional Pan_Position field positions that note independently from −100 (left) through 0 (centre) to +100 (right). These values are interpreted as individual performed events, not a single track-wide volume or pan setting.

When you export Tracks 1–2 to MIDI, their validated pitch, onset, duration and velocity travel as note events. Authored note pan values are translated to MIDI CC10; overlapping notes with distinct pan positions can use separate melodic channels because CC10 is channel-wide. The export represents the performance, not Studio's selected SoundFont or audio effects. Keep the original CSV for all editable instructions and native-SoundFont pan behavior.

See the MIDI expressive-performance guide.

How to author this format

One note event per row; simultaneous pitches may share a tick. Track 2 may select a double-bass SoundFont while using this Pitched format. This is not the Guitar TAB schema.

Keep exactly the supplied headers in their proper order. CSV supports commas inside quoted strings, and empty optional cells retain their position. Event rows are required for playable content; the header-only template is deliberately not playable.

All optional Pan_Position values use integer −100 to +100. Blank preserves the original SoundFont stereo placement, while 0 explicitly centres the note/strike/string. RC1 also accepts the earlier 85-column legacy layout without pan fields.

Composition length uses the declared full-measure final barline rather than the last note onset. Cross-track tempo, meter and composition length must agree. MIDI import into Studio first converts to a SymphonyCSV musical format.
