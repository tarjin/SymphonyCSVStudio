Guitar TAB and MIDI

Tracks 3 and 4 support MIDI export, not MIDI import. Export either track as a standard .mid file for REAPER or other MIDI software. The exported notes represent the musical performance, including pitch, timing, duration and velocity, but a MIDI file does not preserve all the editable guitar-specific instructions in SymphonyCSV TAB CSV.

Keep your original TAB CSV or Project ZIP for editing. The 135-column TAB format can represent string and fret assignments, coordinated chords, strum direction, strum spread, string emphasis and other performance choices that ordinary MIDI cannot reliably reconstruct. Standalone MIDI import remains available only for Piano Roll Tracks 1–2 and Drum Tracks 5–6.

Project ZIP exports include both the authoritative Track_3.csv/Track_4.csv and playable Track_3.mid/Track_4.mid for populated TAB tracks. Project ZIP imports always restore musical Tracks 1–6 from CSV, never from their MIDI companions. The Project ZIP preserves your Studio composition and settings, subject to the SoundFont licensing information provided with the project.

How to author this format

Both Track 3 and Track 4 use six-string Guitar TAB. They are not designated Bass TAB tracks. Stereo placement may be different for each string of the same strum.

Keep exactly the supplied headers in their proper order. CSV supports commas inside quoted strings, and empty optional cells retain their position. Event rows are required for playable content; the header-only template is deliberately not playable.

All optional Pan_Position values use integer −100 to +100. Blank preserves the original SoundFont stereo placement, while 0 explicitly centres the note/strike/string. RC1 also accepts the earlier 129-column legacy layout without pan fields.

Composition length uses the declared full-measure final barline rather than the last note onset. Cross-track tempo, meter and composition length must agree. MIDI import into Studio supports Piano Roll Tracks 1–2 and Drum Tracks 5–6 only; TAB Tracks 3–4 use native CSV for import and standard MIDI for export.
