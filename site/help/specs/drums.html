Importing MIDI panning

When converting a MIDI file to Drums Tracks 5–6, Studio captures the active channel CC10 pan at each note or hit onset and writes a whole-number Pan_Position from −100 (left) to +100 (right). MIDI CC10 64 maps to explicit centre (0). When no pan controller was provided, the cell stays blank, retaining the SoundFont's native placement. MIDI CC121 resets pan to centre. Changes during sustained notes cannot be reproduced as a continuous sweep.

Read the full MIDI pan import explanation for multi-track ordering, controller limitations and conversion behaviour.

Expressive drum performance in MIDI

Each row describes one percussion strike. Its velocity (1–127), timing_offset_ms and optional Pan_Position can vary independently between hits, including hits at the same musical time. This lets you write accents, microtiming and stereo placement into the rhythm itself.

For MIDI export, Tracks 5–6 carry the mapped percussion note, attack velocity and note duration. Optional microtiming is rounded to the nearest representable MIDI tick. Authored pan becomes MIDI CC10; overlapping differently positioned hits may use additional MIDI channels. General MIDI only guarantees drum sounds on channel 10. To retain both the intended kit sounds and independent pan, configure additional channels to use the same kit in a multichannel drum sampler or DAW.

The exported drum note keys reflect Studio's kit mapping and are not necessarily standard GM drum keys. The CSV stays authoritative; MIDI does not include Studio SoundFont samples or audio effects. See the MIDI expressive-performance guide.

How to author this format

Track 5 is Acoustic Drums, Track 6 is Electronic Drums. Both write events for named percussion surfaces. A kit-profile mapping resolves surfaces to the selected SoundFont; do not replace a surface ID with an arbitrary MIDI note number.

Keep exactly the supplied headers in their proper order. CSV supports commas inside quoted strings, and empty optional cells retain their position. Event rows are required for playable content; the header-only template is deliberately not playable.

All optional Pan_Position values use integer −100 to +100. Blank preserves the original SoundFont stereo placement, while 0 explicitly centres the note/strike/string. RC1 also accepts the earlier 20-column legacy layout without pan fields.

Composition length uses the declared full-measure final barline rather than the last note onset. Cross-track tempo, meter and composition length must agree. MIDI import into Studio first converts to a SymphonyCSV musical format.
