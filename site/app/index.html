    KNOWN-GOOD BASELINE

    Stronger master dynamics, still adjustable

    Standard processing now uses a firmer 6 dB knee and +6 dB input drive with matched output trim. The visible defaults remain −20 dB, 3:1, 8 ms attack and 180 ms release.

    Bypass follows the original dry path, leaving track levels unchanged. The output limiter is not a brick-wall guarantee; lower listening volume before testing strong settings.

    ALWAYS-ON OUTPUT STAGE

    Limiter remains separate

    The existing final output limiter remains enabled and unchanged, after the Master EQ. It is not a brick-wall peak guarantee.

    Save to Browser, Recover Session and Project ZIP carry compressor settings. Older saves use the known-good defaults.

    MASTER SIGNAL CHAIN

    Compressor → Graphic EQ → Limiter

    All musical tracks and shared effects join the master before this EQ. Bypassing the compressor does not bypass the EQ, and bypassing the EQ preserves its five saved band settings.

    Five peaking filters (Q = 1) are used for the graphic approximation. EQ is initially bypassed to preserve the Checkpoint 064 sound.
