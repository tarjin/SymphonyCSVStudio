# SymphonyCSV Studio Effects Library

Engine: Tone.js 15.1.22
Technology: Web Audio API
Target: 20 or more virtual effects

Each effect will have:
- A unique identifier
- A defined audio-processing implementation
- Adjustable parameters
- Wet/dry mixing where applicable
- Bypass capability
- Licensing documentation
- Audio verification evidence

An effect is not considered functional until
its audio processing has been tested.

The effects library is used for local audition.
REAPER remains the professional production environment.
